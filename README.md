# industrial-sound-anomaly
Industrial equipment anomaly sound detection
# 工业设备异常声音检测系统 (Industrial Sound Anomaly Detection)

基于卷积自编码器（Convolutional Autoencoder）的工业设备异常声音检测与预警系统。

## 💡 项目背景
工业设备（如电机、水泵、风机）的早期故障通常伴随异常声音。传统人工巡检成本高、漏检率高。本项目旨在通过深度学习技术，仅使用正常声音训练模型，实现对未知异常声音的自动检测与报警，助力工业预测性维护。

## 🚀 核心功能
- **音频上传与录制**：支持上传设备运行声音（.wav）。
- **特征提取**：将音频转换为 Log-Mel 频谱图。
- **异常检测**：自编码器计算重构误差，判定设备状态（正常/异常）。
- **可视化网页**：展示波形、频谱、异常分数，支持阈值调节。
- **硬件联动（规划中）**：边缘计算盒+三色报警灯。

## 🛠️ 技术栈
- **深度学习**：PyTorch, torchaudio
- **数据处理**：librosa, numpy, pandas
- **网页端**：Streamlit
- **硬件端**：树莓派/Jetson Nano（规划）

## 📁 目录结构
- `configs/`: 配置文件

- `src/`: 核心代码（数据加载、模型、训练、推理）
- `app/`: 网页端代码
- `docs/`: 相关文档
